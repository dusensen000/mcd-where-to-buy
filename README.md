# 麦门备选计划：这一餐在这家买不到怎么办？

你已经想好要吃什么，但附近某家麦当劳的当前菜单里没有其中一件餐品。本项目连接麦当劳中国官方 MCP，先确认哪些门店能提供**原餐**；对于菜单中缺少的餐品，只提出同一官方菜单分类下、经餐品详情验证的**备选候选**，并对替换后的整单重新核价。用户可以锁定不愿替换的餐品，也可以设置整单预算。

> 独立开发项目，非麦当劳官方产品。候选替代餐不等同于原餐；口味、配料、营养及过敏原需用户自行核对。本工具只查询，不下单。价格和可售状态以实际下单页为准。

## 适用场景

- 想买的套餐只在部分附近门店当前菜单中出现，想知道去哪家仍能买到原餐。
- 同行者指定的某件餐品不能替换，其他餐品可以调整。
- 希望保留一餐的大部分内容，查看附近门店能否提供经官方整单核价的备选方案。
- 有整单预算，希望过滤超过预算的候选。

## 如何工作

1. `query-nearby-stores` 查找最多 5 家当前营业、支持到店取餐或得来速的门店。
2. `query-meals` 读取各店当前菜单，在所有候选门店中解析目标餐品。名称不明确时返回候选编码，不猜测用户选择。
3. `query-meal-detail` 核对原餐与各店套餐的默认组成；默认组成不同，不能标为原餐。
4. 若某店未验证到原餐，从较明确的官方菜单分类找备选候选；宽泛的“小食甜品/其他”等分类不会用于自动替代。用户也可用 `replacementQueries` 明确指定备选餐品。候选仅代表值得用户考虑的选择，不代表口味或营养等同。
5. `calculate-price` 对每个候选的完整购物篮核价。核价失败、返回餐品或数量不一致的方案不会展示为可购买结果。

输出区分 `exact`（原餐已核价）、`alternatives`（替代餐已核价）、`unavailable`（没有合适候选）、`unverified`（官方核价未确认）、`over_budget`（核价超过预算）和 `menu_error`（菜单查询失败）。这里的“当前菜单不可售”**不等于门店实物缺货**。

## 安装

需要 Node.js 20 或更新版本，以及从[麦当劳 MCP 开放平台](https://open.mcd.cn/mcp)申请的 Token。

```powershell
npm ci
$env:MCD_MCP_TOKEN = Read-Host '输入麦当劳 MCP Token' -MaskInput
npm run doctor
```

`doctor` 只检查官方 MCP 连接和所需工具。程序从进程环境变量读取 Token，不会自动读取 `.env`。

## 使用示例

先在附近候选门店查询餐品的准确名称和编码：

```powershell
node src/cli.js --city 上海 --keyword 人民广场 --search 不素之霸
```

查询“不素之霸双层牛堡 + 薯条”在附近门店的原餐与备选方案：

```powershell
node src/cli.js --city 上海 --keyword 人民广场 --items '[{"query":"4648","quantity":1},{"query":"4810","quantity":1}]'
```

不允许替换薯条，并限制整单预算为 45 元：

```powershell
node src/cli.js --city 上海 --keyword 人民广场 --items '[{"query":"4648","quantity":1},{"query":"4810","quantity":1,"allowAlternative":false}]' --budget 45
```

如果希望“薯条”不可售时考虑“玉米杯”，可在该餐品中加入 `"replacementQueries":["玉米杯"]`；程序仍会检查目标门店菜单与餐品详情，并对替换后的整单核价。

得来速模式加 `--mode drive_through`；可用 `--max-stores 3` 和 `--max-plans 2` 控制查询范围。菜单、价格会变化，示例仅用于说明调用方式。

## 作为 MCP Server 接入

本项目通过 stdio 提供两个只读工具：

| 工具 | 用途 |
| --- | --- |
| `search_meals` | 辅助查找官方菜单中的餐品名称和编码 |
| `plan_meal_alternatives` | 同时查询原餐和替代后的整单方案，核对默认组成与官方实付价 |

参考 [`mcp-config.example.json`](mcp-config.example.json) 设置客户端，将 `${PROJECT_DIR}` 指向本项目绝对路径，并通过客户端的环境变量设置提供 `MCD_MCP_TOKEN`。各客户端的占位符处理方式可能不同。智能体使用步骤见 [`SKILL.md`](SKILL.md)，官方 MCP 调用流程见 [`MCP_INTEGRATION.md`](MCP_INTEGRATION.md)。

## 边界

- 仅比较当前营业门店的到店取餐与得来速菜单，不预测未来时段，也不比较外送。
- 备选依据是官方菜单分类与餐品详情，不提供营养或过敏原安全保证。
- 距离来自官方门店查询，不代表行程时间或排队时间。
- 每店最多核价 12 个候选组合，并返回最多 5 个已核价方案；没有展示的方案不代表不可购买。
- 本工具不创建订单、不领券、不取消订单。
